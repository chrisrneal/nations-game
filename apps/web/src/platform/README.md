# platform (lane P)

Everything that touches the browser or the device lives here: the Web Worker
that runs the sim, the Comlink bridge, the LocalHost the interface talks to,
IndexedDB saves, feedback (haptics, sound) and the install prompt. The
service worker is generated by vite-plugin-pwa from `apps/web/vite.config.ts`,
which is also lane P.

Why a separate folder: the interface (lane U) must never import the sim
directly and bypass the Host seam (S3); `apps/web/src/boundary.test.ts` checks
that the interface imports only `platform/index.ts` from here.

Files:
- `index.ts` - the only file the interface may import: `createHost()`, the
  install prompt, feedback and types.
- `engine.ts` - `GameEngine`: the sim session. No clock (K3): every command
  answers with the new View. No Worker code, so it is tested in Node.
- `worker.ts` - exposes one `GameEngine` over Comlink. Puzzle generation runs
  here, off the interface thread.
- `localHost.ts` - `LocalHost`, the `GameHost` the interface uses: profiles
  (the picker, switching, the grown-ups' menu, K7), today's daily (the day
  number from the device's calendar, D18), the bonus round once the daily
  is finished, practice boards, an autosave after every command, and a
  record of every finished daily for the streak. Each profile keeps its own
  save slots (`p1/daily-main-20400`). On the first launch after profiles
  arrived it folds the old single save into the first profile.
- `saves.ts` - save slots and the profile book in IndexedDB (database
  `snacks`, version 2: stores `slots` and `meta`; memory store for tests).
- `feedback.ts` - sound (a mute for each profile, unlocked by the first touch,
  asleep while hidden) and haptics (K13). `sounds.ts` holds the recipes for
  the 13 cues; `fakeAudio.ts` is a stand-in audio graph for tests only.
- `backStack.ts` - the Back button closes sheets before it leaves the game.
- `updates.ts` / `swRegister.ts` - "a new version is ready", never automatic.
- `guards.ts` / `storage.ts` - no long-press menus, selection or pinch; a request
  that the browser keep the saves.
- `install.ts` - the install prompt (`beforeinstallprompt`, iOS instructions).
