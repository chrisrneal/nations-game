## What happened to the rule change

Before prompt 09 merged, this prompt built and tuned a supplier-side trade gain:
exporters earn a bonus on the share of their own surplus sold into a deficit, with a
separate rate `exportGainsBp`. Tuned on seeds 1001-1800 at 18, it took the graded
median to +18.6-19.2% per range and pushed India out of the top three scorers (it had topped 35-45% of games).
But prompt 09 merged first with the same idea in a more general form: each side gains
by the share of its *own* imbalance cleared, one rate, capped each month (RULES 3.3).
Both rules fix the same fault: the old bonus was scaled by the buyer's deficit, so
Australia got 11% of the bonus for selling all its energy to China. Keeping both would
pay exporters twice, so prompt 09's rule was kept and `exportGainsBp` dropped.

## Harness changes used for this report

- `npm run harness -- gate1 --ranges N` runs N consecutive ranges of `--games`
  seeds from `--seed`, prints one summary row per range plus the pooled row, then
  the pooled report and each range's report. It exits 1 unless every range and the
  pooled run pass.
- New line in every report: "Pairs at +15% or more" (the share of paired runs that
  clear the line), overall and per nation.
- `--suite gate1` is the same as `gate1`. An unknown command, suite or flag stops
  with a plain message and exit code 2 (Gate 1 review finding: `--suite gate1` used
  to run the wrong command and exit 0).
